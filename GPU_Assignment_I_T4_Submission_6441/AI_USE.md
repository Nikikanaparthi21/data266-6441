# AI Use - GPU Assignment I

I used an AI assistant to create a first-cut organization for the analysis, identify missing
requirements, calculate derived quantities from my saved measurements, and explain precision,
roofline, attention-memory, and thermal concepts so I could understand them more deeply. I used
the assistant's work as a starting point, reviewed the calculations against my raw files, and
kept explicit limitations where the original run did not contain a required measurement. No RTX
results, OOM failures, reservations, or sustained-load results were invented.
